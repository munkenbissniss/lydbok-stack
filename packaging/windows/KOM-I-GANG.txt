LYDBOK-STACK FOR WINDOWS – KOM I GANG
=====================================

1. Installer Docker Desktop (https://www.docker.com/products/docker-desktop/)
   og start det.

2. Dobbeltklikk Start.bat.
   Viser Windows «Windows beskyttet PCen», trykk «Mer informasjon» og
   «Kjør likevel». Det trengs bare én gang.

3. Veiviseren stiller noen spørsmål, så starter alt av seg selv.
   Kjører Plex-stack allerede på PC-en, kan lydbøkene bruke nedlasterne derfra.

   Mediemappe skrives med vanlige skråstreker, f.eks. D:/Media

4. Lytt:        http://localhost:13378  eller appen «Audiobookshelf»
   Dashboard:   http://localhost:3100

Oppdatere senere: dobbeltklikk Oppdater.bat.
Mer hjelp: README.md
