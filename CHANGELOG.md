# Endringslogg

## 1.0.0

Første versjon.

- Audiobookshelf for lydbøker og podkaster, med apper for iPhone og Android.
- Bookshelf (videreføring av Readarr) følger forfattere og serier og henter lydbøker selv.
- Veiviser som finner Plex-stack på maskinen og kan bruke nedlasterne derfra.
- Egen nedlasting når den står alene: qBittorrent bak VPN, NZBGet for Usenet, Prowlarr og FlareSolverr.
- Autooppsett: administrator og bibliotek i Audiobookshelf, rotmappe, profil og nedlastingsklienter
  i Bookshelf, kategorier i qBittorrent og NZBGet, Bookshelf koblet til Prowlarr, dashboard med tall.
- Nettverksdeling (NFS/SMB), rolig modus og kjøling.
- Pakker for Linux, macOS og Windows.
